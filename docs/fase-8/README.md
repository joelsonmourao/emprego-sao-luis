# Fase 8 — Audiência e alertas

Inscrição opcional com double opt-in, preferências, consentimento auditável, descadastro, fila BullMQ e provedor Resend desacoplado. Nenhuma vaga é bloqueada por cadastro ou follow. Link do canal oficial do WhatsApp é configurável.

Envio real exige `RESEND_API_KEY`, domínio verificado e `EMAIL_FROM`. Web Push, conta completa, vagas salvas, exportação e exclusão dos dados ainda não estão concluídos.
