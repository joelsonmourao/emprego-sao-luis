# Fase 8 — Audiência e alertas

Inscrição opcional com double opt-in, preferências, consentimento auditável, descadastro, fila BullMQ e provedor Resend desacoplado. Nenhuma vaga é bloqueada por cadastro ou follow. Link do canal oficial do WhatsApp é configurável.

Contas de candidatos usam link mágico de 15 minutos e sessão separada da administração. Há vagas salvas, exportação JSON, saída e exclusão/anonymização self-service com registro de consentimento. Envio real exige `RESEND_API_KEY`, domínio verificado e `EMAIL_FROM`. Web Push continua opcional e ainda depende de VAPID/HTTPS.
