# Fase 9 — Monetização

AdSense fica desligado por padrão e só carrega com feature flag, publisher configurado e consentimento. O slot da vaga aparece estritamente depois do botão de candidatura, com altura reservada contra CLS. `ads.txt` não publica identificador falso.

O banco possui anunciantes, campanhas, slots, criativos e eventos para venda direta, sempre com disclosure. Gestão comercial, relatórios e campanhas reais dependem de dados e aprovação comercial.
